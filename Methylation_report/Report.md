## Overview

This report validates the PacBio HiFi 5mCpG methylation calling pipeline
(`nf-longread`) on chromosome 22 of the Ashkenazim Trio reference
samples (HG002/HG003/HG004, NIST). Methylation calls are generated by
`pb-CpG-tools aligned_bam_to_cpg_scores` using the primrose-calibrated
model on phased HiFi BAMs (HiPhase). The report covers:

1.  Coverage and call-rate QC
2.  Beta value distribution
3.  CpG genomic context annotation
4.  Allele-specific methylation (ASM) landscape
5.  Trio concordance

## 1. Data Loading

:::: cell
`<details class="code-fold">
<summary>`{=html}Code`</summary>`{=html}

``` {.r .cell-code}
# --- pb-CpG-tools BED files ---
# Expected path: <PLACEHOLDER: adjust to your repo structure>
BED_DIR <- "../deployment/benchmark/trio_benchmark_results/test_run/methylation/pb-cpg"

pcpg_hap <- list.files(BED_DIR, 
                       pattern = "*bed.gz$", 
                       full.names = TRUE) %>%
  map(~ fread(.x, skip = 8) %>%
        mutate(
          sample = gsub(".hap[0-9]+.bed.gz$", "", basename(.x))
        ) %>%
        relocate(sample, type, .before = `#chrom`) %>%
        filter(cov >= COV_MIN, 
               `#chrom` == CHR)
  ) %>%
  purrr::reduce(bind_rows) %>%
  dplyr::rename(chrom = `#chrom`)

# Combined (hap1 + hap2) per site
pcpg_combined <- pcpg_hap %>%
  group_by(sample, chrom, end) %>%
  summarise(
    beta      = sum(est_mod_count) / sum(cov),
    cov_total = sum(cov),
    .groups   = "drop"
  ) %>%
  filter(cov_total >= COV_MIN)

cat(sprintf(
  "Loaded %s CpG sites across %s samples (combined, cov >= %d)\n",
  format(nrow(pcpg_combined), big.mark = ","),
  n_distinct(pcpg_combined$sample),
  COV_MIN
))
```

## 4. CpG Genomic Context Annotation

Methylation patterns differ systematically by genomic context: CpG
islands are typically hypomethylated (active regulatory regions), while
CpG shores and open-sea CpGs are predominantly hypermethylated.

:::: cell
`<details class="code-fold">
<summary>`{=html}Code`</summary>`{=html}

``` {.r .cell-code}
# Build annotatr annotation for hg38 chr22
annots <- build_annotations(genome = "hg38",
                             annotations = c("hg38_cpg_islands",
                                             "hg38_cpg_shores",
                                             "hg38_cpg_shelves",
                                             "hg38_cpg_inter"))

# Convert pcpg_combined to GRanges for annotation
gr_cpg <- pcpg_combined %>%
  filter(sample == "HG002") %>%          # annotate once, same positions for all
  makeGRangesFromDataFrame(
    seqnames.field = "chrom",
    start.field    = "end",
    end.field      = "end",
    keep.extra.columns = TRUE
  )

annotated <- annotate_regions(
  regions     = gr_cpg,
  annotations = annots,
  ignore.strand = TRUE,
  quiet         = TRUE
) %>%
  as_tibble() %>%
  select(seqnames, start, beta, cov_total, annot.type) %>%
  mutate(
    context = case_when(
      str_detect(annot.type, "islands") ~ "CpG island",
      str_detect(annot.type, "shores")  ~ "CpG shore",
      str_detect(annot.type, "shelves") ~ "CpG shelf",
      str_detect(annot.type, "inter")   ~ "Open sea",
      TRUE                              ~ "Other"
    )
  )

annotated %>%
  ggplot(aes(x = beta, fill = context, colour = context)) +
  geom_density(alpha = 0.3, linewidth = 0.8) +
  facet_wrap(~ context, ncol = 2) +
  labs(
    x     = "Methylation beta value",
    y     = "Density",
    title = "Figure 3. Beta value distribution by CpG genomic context (HG002)",
    subtitle = "CpG islands: hypomethylated; open sea: hypermethylated — expected pattern"
  ) +
  scale_fill_brewer(palette  = "Set1") +
  scale_colour_brewer(palette = "Set1") +
  theme(legend.position = "none")
```

## 5. Allele-Specific Methylation (ASM) Landscape

HiPhase haplotype-resolved calling allows direct comparison of
methylation between the two parental haplotypes at each CpG site. Sites
with large \|hap1 - hap2\| differences are candidate ASM loci.

::: cell
`<details class="code-fold">
<summary>`{=html}Code`</summary>`{=html}

``` {.r .cell-code}
asm <- pcpg_hap %>%
  select(sample, chrom, end, type, beta = mod_score, cov) %>%
  mutate(beta = beta / 100) %>%       # mod_score is 0-100, convert to 0-1
  pivot_wider(
    names_from  = type,
    values_from = c(beta, cov),
    names_sep   = "_"
  ) %>%
  filter(!is.na(beta_hap1), !is.na(beta_hap2)) %>%
  mutate(asm_delta = abs(beta_hap1 - beta_hap2))
```

## 6. Trio Concordance

Methylation beta values should be highly concordant across the
Ashkenazim Trio at constitutively methylated and unmethylated loci,
confirming pipeline stability across samples sequenced in independent
runs.

``` {.r .cell-code}
  drop_na()
```
